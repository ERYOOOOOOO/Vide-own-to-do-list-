# Mission Control — Personal Dashboard

เว็บแดชบอร์ดส่วนตัว ติดตามเป้าหมายชีวิต ตารางประจำวัน weekly focus โปรแกรมออกกำลังกาย การสอบ โปรเจกต์ habit tracker และ **ระบบเหรียญแลกรางวัล** ธีม minimal white + matcha

เก็บข้อมูลในเครื่อง (localStorage) ไม่ต้องล็อกอิน ไม่ต้องต่อเซิร์ฟเวอร์ — เปิดไฟล์แล้วใช้ได้เลย และแชร์/ย้ายข้อมูลไปเครื่องอื่นได้เอง

## ระบบเหรียญ (Coin) 🪙
สะสมเหรียญจากการทำสิ่งดี ๆ แล้วเอาไปแลกรางวัลให้ตัวเอง:

| ทำอะไร | ได้เหรียญ |
|---|---|
| ติ๊ก habit 1 วัน (ในตาราง streak) | +10 🪙 |
| ทำ Weekly Focus 1 รายการสำเร็จ | +20 🪙 |
| ทำท่าออกกำลังกาย 1 ท่าสำเร็จ | +15 🪙 |
| ทำภารกิจประจำวัน 1 รายการสำเร็จ | +2 🪙 |

- เหรียญจะไม่ได้ซ้ำจากรายการเดิม (กดสลับไปมาก็ไม่ฟาร์มเหรียญได้) — habit ได้วันละ 1 ครั้งต่อ 1 นิสัย จึงเป็นแหล่งเหรียญหลักที่เติมได้ทุกวัน
- ยอดเหรียญโชว์บนแถบบนสุดตลอดเวลา

### ร้านแลกรางวัล
- การ์ดรางวัลเริ่มต้น: ดื่ม Pepsi (30), ของหวาน (35), ดู Shorts 15 นาที (40), เล่นเกม 1 ชม. (60), ดูหนัง 1 เรื่อง (80), วันพักผ่อนเต็มวัน (300)
- แก้ชื่อ/ราคาได้ กด **+ เพิ่มรางวัล** เพื่อสร้างรางวัลใหม่ กด ✕ เพื่อลบ
- กด **แลก** เพื่อใช้เหรียญ (ถ้าเหรียญไม่พอปุ่มจะกดไม่ได้) ทุกครั้งที่แลกจะบันทึกใน **ประวัติการแลก**

## ภารกิจประจำวัน (Daily Mission) 🎯
การ์ด "ภารกิจประจำวัน" เป็นรายการเช็คลิสต์ที่ **รีเซ็ตอัตโนมัติทุกเที่ยงคืน** (พอเปิดเว็บครั้งแรกในวันใหม่ ระบบจะเคลียร์เครื่องหมายทั้งหมดให้เริ่มทำใหม่ และปลดล็อกให้เก็บเหรียญได้ใหม่ในวันนั้น — เหรียญที่เก็บไว้แล้วไม่หาย)

- กด **+ เพิ่มภารกิจ** เพื่อสร้างภารกิจใหม่ กด ✕ เพื่อลบ แก้ข้อความได้โดยพิมพ์ทับในช่อง
- ติ๊กภารกิจสำเร็จ ได้ **+2 🪙** ต่อรายการ (ได้ครั้งเดียวต่อวันต่อรายการ)

## ตารางออกกำลังกายรายสัปดาห์ 💪
การ์ด "โปรแกรมออกกำลังกาย" มีตารางประจำสัปดาห์อยู่ด้านบน วันนี้จะถูกไฮไลต์สีเขียว และแท็บท่าออกกำลังกายจะเด้งไปที่โปรแกรมของวันนี้ให้อัตโนมัติ:

| วัน | โปรแกรม |
|---|---|
| จันทร์ | Push |
| อังคาร | Pull |
| พุธ | Leg |
| พฤหัสบดี | Push |
| ศุกร์ | Pull |
| เสาร์ | Leg |
| อาทิตย์ | พัก |

- คลิกวันในตารางเพื่อสลับไปดูท่าของวันนั้นได้
- **พอขึ้นวันจันทร์ใหม่** (ครั้งแรกที่เปิดเว็บในสัปดาห์ใหม่) ระบบจะ **รีเซ็ตเครื่องหมายท่าออกกำลังกายทั้งหมด** ให้เริ่มติ๊กใหม่ และปลดล็อกให้เก็บเหรียญออกกำลังกายได้ใหม่ในสัปดาห์นั้น (เหรียญที่เก็บไว้แล้วไม่หาย)

## แชร์ / สำรองข้อมูล (ย้ายไปเครื่องอื่น)
เพราะข้อมูลเก็บในเครื่อง จึงย้ายด้วยตัวเองผ่านปุ่ม **⚙️ จัดการข้อมูล** บนแถบบน:

**ส่งออก (เครื่องเดิม):**
1. กด **จัดการข้อมูล** → หัวข้อ "ส่งออก / แชร์"
2. กด **📋 คัดลอก** (ได้โค้ดข้อมูลทั้งหมด) หรือ **💾 ดาวน์โหลดไฟล์** (ได้ไฟล์ `mission-control-backup.json`)

**นำเข้า (เครื่องใหม่ / เครื่องปลายทาง):**
1. เปิดเว็บบนเครื่องนั้น → กด **จัดการข้อมูล** → หัวข้อ "นำเข้า"
2. วางโค้ดที่คัดลอกมา หรือกดเลือกไฟล์ backup
3. กด **นำเข้าข้อมูล** (ข้อมูลเดิมในเครื่องนั้นจะถูกเขียนทับด้วยของที่นำเข้า)

> หมายเหตุ: เป็นการซิงค์แบบ manual ไม่ใช่ real-time — ถ้าแก้ในเครื่อง A แล้วอยากให้เครื่อง B ตรงกัน ต้อง export จาก A แล้ว import ที่ B อีกครั้ง

## Deploy ขึ้นเว็บฟรีด้วย Netlify Drop
1. ไปที่ https://app.netlify.com/drop
2. ลากทั้งโฟลเดอร์ `Schedule` (ที่มี `index.html`, `style.css`, `app.js`) ไปวาง
3. Netlify ให้ URL ฟรีทันที เปิดได้ทุกอุปกรณ์ (ข้อมูลของแต่ละอุปกรณ์แยกกัน ใช้ export/import เพื่อย้าย)

## โครงสร้างไฟล์
- `index.html` — โครงหน้าเว็บ 8 ส่วน + ร้านแลกรางวัล + modal จัดการข้อมูล
- `style.css` — ธีม minimal white + matcha
- `app.js` — ลอจิกทั้งหมด (localStorage, ระบบเหรียญ, render, export/import)
- `README.md` — ไฟล์นี้

## หมายเหตุ
- ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ — ล้าง cache/site data ของเบราว์เซอร์แล้วข้อมูลจะหาย จึง export เก็บไฟล์ backup ไว้เป็นระยะ
- ทำงานแบบ offline 100% ไม่ต้องต่อเน็ตหลังโหลดหน้าเว็บครั้งแรก
